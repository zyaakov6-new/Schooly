## 🚀 Quick Start

### 1. Firebase Setup (Required – 5 min)

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create new project → Enable **Authentication** (Email/Password + Google)
3. Enable **Firestore Database** (Production mode)
4. Enable **Firebase Storage**
5. Enable **Firebase Cloud Messaging**
6. Install FlutterFire CLI:
   ```bash
   dart pub global activate flutterfire_cli
   ```
7. Configure Firebase:
   ```bash
   flutterfire configure --project=YOUR_PROJECT_ID
   ```
   This auto-generates `lib/firebase_options.dart` with correct values.

8. Download `google-services.json` → place in `android/app/`
9. Download `GoogleService-Info.plist` → place in `ios/Runner/`

### 2. Deploy Firebase Rules
```bash
firebase deploy --only firestore:rules,storage
firebase deploy --only firestore:indexes
```

### 3. Install & Run
```bash
flutter pub get
flutter run
```

## 🔒 Firebase Security Rules

Firestore rules enforce:
- Users can only access families they're members of
- `createdBy` must match `request.auth.uid`
- No anonymous reads/writes

## 📋 Smart Inbox Parser

Paste any WhatsApp/SMS message and the parser extracts:

| Input | Extracted |
|-------|-----------|
| `מחר טיול – צריך נעלי הליכה, 50 ש"ח, חזור 17:00` | Date: tomorrow, Payment: ₪50, Return: 17:00 |
| `Math test on Thursday – bring calculator` | Date: next Thursday, Event type: Test |
| `Soccer practice every Monday 16:00-17:30` | Recurring event, Mon 16:00-17:30 |
